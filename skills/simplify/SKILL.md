# Simplify

Inspect only the current diff. Remove duplication, dead code, accidental
complexity, and generated clutter when behavior remains covered by existing
proof. Reuse nearby helpers instead of adding abstractions. Do not start a
baseline cleanup, refactor adjacent code, or widen the task.
